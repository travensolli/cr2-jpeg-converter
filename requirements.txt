# Dependências de execução do CR2 Converter.
#
# São usados limites mínimos (>=) em vez de versões exatas (==): o projeto não
# depende de detalhes internos dessas bibliotecas e travar versões geraria
# conflitos desnecessários com outros pacotes do ambiente. Cada mínimo abaixo
# corresponde à primeira versão que oferece a API realmente utilizada.

# Interface gráfica. Qt 6 é necessário por causa de QThreadPool/Signal com
# tipos Python e da política de arredondamento de High-DPI usada na inicialização.
PySide6>=6.5

# Leitura dos arquivos RAW. Empacota o LibRaw junto (não é preciso instalar
# nada além do pip). O mínimo 0.19 garante extract_thumb() e as classes de
# exceção LibRaw* usadas no tratamento de erros.
rawpy>=0.19

# Gravação do JPEG e redimensionamento. O mínimo 10.0 garante as enumerações
# Image.Resampling e Image.Transpose como API oficial.
Pillow>=10.0

# Leitura e escrita do bloco EXIF. O rawpy entrega apenas pixels, sem
# metadados; o piexif lê o EXIF direto do CR2 (que é um TIFF) e o grava no JPEG.
piexif>=1.1.3

# numpy não é listado porque vem obrigatoriamente com o rawpy (postprocess()
# devolve um ndarray). Instalá-lo separadamente não é necessário.

# ---------------------------------------------------------------------------
# Combinação usada nos testes desta versão (Windows 10, Python 3.14.3):
#   PySide6 6.11.1 · rawpy 0.27.0 (LibRaw 0.22.1) · Pillow 12.3.0 · piexif 1.1.3
# ---------------------------------------------------------------------------
